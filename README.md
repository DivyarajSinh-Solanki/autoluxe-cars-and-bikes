# AutoLuxe - Cars & Bikes Rental, Purchase & Blogging Platform

A responsive web application designed for an academic web development final project. Built using pure **HTML5**, **CSS3**, and **JavaScript (ES6)**.

## Project Features
1. **Explore Vehicles & Reviews**:
   - Filter listings by Category (**Cars / Bikes**) and Option Type (**For Rent / For Sale**).
   - Real-time search across titles, descriptions, and engine specs.
2. **Saved Garage (Favorites)**:
   - Bookmark vehicles to your personal saved collection.
   - Persistent storage using `localStorage`.
3. **Authentication & Form Validation**:
   - Pure JavaScript modal validation for Login and Registration.
   - Real-time email pattern matching (Regex) and password length checking.
   - Simulated session handling.
4. **Interactive Details & Specifications Modal**:
   - High-resolution view, engine specs, horsepower, top speed, and full blog review.
5. **Dynamic Posting**:
   - Add new vehicle listings or reviews dynamically using pure DOM manipulation and state persistence.

## How to Run & Deploy
1. Extract the ZIP archive.
2. Open `index.html` directly in any standard web browser.
3. Push to GitHub and activate **GitHub Pages** under Repository Settings to make it live.
